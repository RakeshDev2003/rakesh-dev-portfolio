# Rakesh Portfolio

A premium, light-themed personal developer portfolio built with Next.js App Router, React, Tailwind CSS, Framer Motion, Lucide React, React Icons, Swiper, React Type Animation, React CountUp, and React Intersection Observer.

## Features

- Fully responsive layout
- Sticky navbar with active section tracking
- Smooth scrolling and reveal-on-scroll motion
- Hero typing effect
- Skills tabs
- Project cards with featured support
- Services, timeline, testimonials, stats, and contact sections
- All editable content in one file: `src/data/portfolio.js`
- Light-only design system with premium spacing and shadows

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Edit content

Update only `src/data/portfolio.js` to change:

- name, role, and hero copy
- social links
- skills
- projects
- services
- experience and education
- testimonials
- stats
- contact details
- footer links
